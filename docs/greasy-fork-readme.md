# YouTube Cleaner（YouTube 淨化大師）

純淨、快速、可自訂的 YouTube 體驗強化腳本。

YouTube Cleaner 會在瀏覽器端隱藏 Shorts、低訊號推薦、合輯、廣告干擾與其他雜訊內容，並提供新分頁開啟、黑白名單、訂閱保護、設定備份等功能。它不會修改你的 YouTube 帳號資料，也不會把觀看紀錄或個人設定上傳到外部伺服器。

## 最新版本：v2.1.15

本次更新修復播放頁右側推薦影片的點擊行為：當「影片開新分頁」啟用時，點擊右側推薦卡片的文字區或新版 `yt-lockup-view-model` 卡片，現在會正確開啟新分頁，不會再直接跳轉目前頁面。

## 主要功能

### 隱藏干擾內容

- 封鎖 Shorts：首頁、搜尋、側邊欄與推薦區的 Shorts。
- 隱藏推薦合輯與 Mix：減少被演算法帶走的連續推薦。
- 隱藏低訊號影片：依觀看數、發布時間與寬限期判斷。
- 隱藏過短或過長影片：可自訂影片時長範圍。
- 隱藏指定關鍵字、頻道與區塊標題。
- 隱藏 Premium 推廣、干擾區塊與部分廣告相關元素。

### 保留你想看的內容

- 頻道白名單：指定頻道永遠保留。
- 關鍵字白名單：標題包含指定字詞時保留。
- 會員影片白名單：針對會員限定內容提供獨立豁免。
- 訂閱保護：自動感應訂閱頻道，避免低觀看數規則誤傷你已訂閱的頻道。
- 頻道頁豁免：可在頻道頁停用內容過濾，避免漏看作者的影片。

### 改善瀏覽體驗

- 影片預設開新分頁：保留目前列表位置，不被 YouTube 單頁跳轉打斷。
- 通知中心影片也可開新分頁。
- 自動處理 YouTube 反廣告封鎖彈窗。
- 支援繁中、簡中、英文、日文介面。
- 支援繁簡互通關鍵字過濾。
- 可匯出與匯入 JSON 設定，方便備份或換裝置。

## 安裝方式

1. 安裝 Tampermonkey 或相容的 Userscript 管理器。
2. 在 Greasy Fork 點擊「安裝此腳本」。
3. 開啟 YouTube。
4. 點擊瀏覽器右上角的 Tampermonkey 圖示，選擇「淨化大師設定」調整功能。

建議安裝後先用預設設定使用一段時間，再依自己的觀看習慣調整黑白名單、低觀看數門檻與影片時長範圍。

## 設定入口

安裝後，在 YouTube 頁面點擊 Tampermonkey 圖示，可以看到 YouTube Cleaner 的設定選單。設定大致分為：

- 內容過濾：啟用或停用各種過濾規則。
- 名單管理：新增或移除黑名單、白名單、會員白名單。
- 體驗設定：開新分頁、字型修正、頻道頁豁免。
- 系統工具：語言切換、Debug Mode、統計、設定匯出與匯入。

## 黑白名單寫法

一般輸入會使用「包含比對」：

```text
Some Channel
```

這會匹配任何包含 `Some Channel` 的頻道或文字。

如果要精確匹配，請在前面加上等號：

```text
=Some Channel
```

這只會匹配完整名稱為 `Some Channel` 的項目。

## 規則邏輯簡介

YouTube Cleaner 使用強規則與弱規則：

- 強規則：Shorts、廣告、合輯、Premium 推廣、會員限定等，通常不受一般白名單影響。
- 弱規則：低觀看數、影片時長、關鍵字、頻道、區塊標題等，可以被白名單豁免。
- 訂閱保護主要用來保護低觀看數規則，不會讓所有黑名單規則失效。

這樣做是為了避免「想保留某個頻道」時，同時讓 Shorts、廣告或合輯重新出現。

## 常見問題

### 為什麼有些內容沒有立刻消失？

YouTube 是單頁應用，內容會在捲動與切換頁面時動態載入。腳本會持續監聽頁面變化並重新掃描，通常稍等一下或切換頁面後會自動處理。

### 為什麼某個我想看的影片被隱藏？

可以把頻道加入白名單，或把標題中穩定出現的關鍵字加入關鍵字白名單。如果是會員限定內容，請使用會員白名單。

### 為什麼某些 YouTube 介面改版後功能失效？

YouTube 會不定期調整網頁結構。若你發現新版卡片、按鈕或推薦區沒有被正確處理，可以回報問題，最好附上發生頁面、你點擊的位置，以及相關 HTML 片段或截圖。

### 這個腳本會影響帳號或上傳資料嗎？

不會。腳本在瀏覽器端執行，只透過 Tampermonkey 儲存本機設定。它不會登入你的帳號、不會修改訂閱、不會刪除觀看紀錄，也不會把你的資料上傳到作者伺服器。

## 權限說明

腳本會使用 Tampermonkey 的本機儲存與選單功能：

- `GM_getValue` / `GM_setValue`：儲存你的設定、黑白名單與偏好。
- `GM_registerMenuCommand`：在 Tampermonkey 選單中提供設定入口。
- `GM_addStyle`：注入隱藏 Shorts、廣告與干擾區塊所需的樣式。
- `GM_setClipboard`：匯出設定時將 JSON 複製到剪貼簿。
- `GM_info`：顯示目前腳本版本。

外部資源只用於 OpenCC 繁簡轉換函式庫；如果載入失敗，腳本會降級運作。
